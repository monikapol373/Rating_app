# Store Rating App

A web application where users can rate stores.

 Tech Stack
- Backend: NestJS
- Database: MySQL
- Frontend: React

 User Roles
- Admin: Manage users and stores
- Normal User: Rate stores
- Store Owner: View store ratings

## How to Run

1. Start XAMPP (Apache + MySQL)
2. Open phpMyAdmin and create database: store_rating_db

**Backend:**
cd backend
npm install
npm run start:dev

**Frontend:**
cd frontend
npm install
npm run dev

3. Open browser: localhost:5173
